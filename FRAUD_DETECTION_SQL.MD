# Fraud Detection SQL and Email Generation

## Task 1 — SQL to find emails of 
## creators with flagged tracks

Write a SQL query that finds the 
email addresses of creators whose 
tracks have suspicious play patterns 
based on the data already identified.

The query should:

1. Join the audio_tracks table with 
  the profiles or auth.users table 
  to get the creator's email
2. Join with the play_sessions table 
  to get play counts and unique 
  listener counts
3. Return the following columns:
  - creator email
  - creator display name or username
  - track title
  - total play count
  - unique listener count
  - unique IP count
  - play to listener ratio

Filter for tracks where:
- Total plays exceed 100
AND
- Unique listener count is 3 or fewer
OR
- Play to listener ratio exceeds 50

Order by total plays descending.

Run this query and display the 
results in the admin dashboard 
fraud review section.

## Task 3 — Admin Dashboard Integration

Add a Send Warning Email button 
to each flagged creator row in 
the fraud review dashboard.

When clicked it opens a pre-populated 
email composer with the appropriate 
template already filled in based 
on the creator's fraud status:

fraud_status = hold: 
loads the payout withheld template

fraud_status = flagged or monitor: 
loads the warning monitoring template

The admin can review and edit 
the email before sending.

On send:
- Record the email sent in the 
 creator_fraud_analysis table:
 warning_email_sent: boolean default false
 warning_email_sent_at: timestamptz | null
- Update the record to reflect 
 that the creator has been contacted
